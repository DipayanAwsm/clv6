==========
Frontend (UI Layer)
React, Vite, JavaScript, HTML, CSS, Axios Used for building interactive dashboards, uploading CSV
data, and displaying CLV insights.
Backend (API Layer)
FastAPI, Python, Uvicorn, Gunicorn Handles API requests, processes data, and serves ML predictions.
Machine Learning Layer
Pandas, Scikit-learn, XGBoost, Random Forest, SHAP Performs data preprocessing, feature
engineering, model training, and explainability.
Data Layer
CSV files, Pandas DataFrames Stores and processes structured input/output data.
API Communication
REST APIs, JSON, Axios Enables communication between frontend and backend.
Deployment Stack
Azure App Service (Backend), Azure Static Web Apps (Frontend) Hosts and runs the application in the
cloud.
